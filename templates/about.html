About This Project

Project Overview

The Skill Gap Analyzer is a web application that helps users evaluate their current skills and identify the gap required for a desired job role. It provides personalized suggestions to improve career readiness.

How It Works

1. User selects a role and enters skills or uploads resume
2. System extracts and processes the skills
3. Skills are compared with required role skills
4. Missing skills are identified
5. Learning recommendations are provided
